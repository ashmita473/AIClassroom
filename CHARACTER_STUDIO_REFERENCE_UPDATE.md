# Character Studio — Reference Update

The character customizer has been redesigned around the supplied reference image.

Key points:
- The supplied reference character is used as the exact visual base for the Girl preview.
- A Boy base keeps the same proportions and reference-inspired body silhouette.
- The UI follows the reference structure: left color rail, centered character preview,
  right vertical tools, bottom category strip, and saved-character thumbnails.
- No emoji-based character artwork is used.
- The original XP ownership/unlock system remains connected to the wardrobe.
- Camera button uses the browser print/snapshot flow for now.
- Category tabs are functional and filter the saved/wardrobe items.
- The server-side customization and XP purchase actions remain in StudentController.

The supplied reference image is a user-provided source and is included only as the
character base asset for this project.
