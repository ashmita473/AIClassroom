# Curriculum Editor Update

- Improved teacher curriculum contrast so cards use dark blue backgrounds with high-contrast white/cyan text.
- Added module creation/editing.
- Added lesson creation/editing and lesson settings.
- Added a Word-style lesson editor with font family, font size, bold, italic, underline, lists, alignment, links and image URL insertion.
- Added editable Introduction, Explanation, Examples, Teacher Focus and Student Notes Template sections.
- Added inline activity creation/editing/deletion with activity type, XP and order.
- Added quiz linking to curriculum lessons.
- Student lesson navigation now opens the lesson directly when a student clicks a lesson card.
- Student lesson rendering supports the formatted lesson HTML saved by the editor.
- Existing database columns are reused for lesson rich content, so this update does not require a new migration for the editor fields.
